# Research Plan

## First Pass

Build the public register from three already-available lanes:

1. The local `Clinton-NATO-European-Security` workbench.
2. The local `strobe-talbott-foia` manifest and text cache.
3. Public official pages from the Clinton Library, NARA Catalog, State FOIA, and
   the Office of the Historian.

Google Drive material should be used as a local discovery accelerator, not as
public provenance, until each file is matched to an official public source or
the user approves publication of the Drive metadata.

## Priority Questions

- Which NSC, Principals Committee, Deputies Committee, and interagency meeting
  records directly shaped NATO enlargement policy?
- Which Summaries of Conclusions record decisions on enlargement, NATO-Russia,
  Partnership for Peace, Madrid, accession, Senate ratification, CFE, OSCE,
  NATO-EU/ESDI, Kosovo, and the Washington NATO Summit?
- Which presidential memcons and telcons give the best documentary spine for
  Clinton, Yeltsin, Central European leaders, allied leaders, and NATO
  leadership?
- Which State FOIA and Strobe Talbott records fill gaps not covered by
  presidential records?
- Which NARA Scout file-unit leads can be promoted quickly to document-level
  records with dates, page spans, and source images?

## Page-Budget Rule

The target is a 1000-page package, not a 1000-item bibliography. Records enter
the page budget only after a page count is known or can be verified from a
trusted release packet. Broad file-unit leads can shape the search but should
not count toward the 1000 pages until they become document-level records.
